Fundamentos de GWR

¿Autocorrelación o no estacionariedad?

  • lm() asume errores independientes y estacionariedad de los coeficientes (relación global).

  • Variogramas o Moran’s I diagnostican autocorrelación de errores, no que la relación sea constante en el espacio

Del modelo global al modelo local

OLS global

\[y_i = \beta_0 + \sum_{j=1}^{k} \beta_j x_{ij} + \varepsilon_i\]

Coeficientes \(\beta_j\) constantes.

GWR

\[y_i = \beta_0(s_i) + \sum_{j=1}^{k} \beta_j(s_i) x_{ij} + \varepsilon_i\]

Coeficientes \(\beta_j(s_i)\) indexados por la ubicación \(s_i = (u_i, v_i)\) del punto \(i\)

un modelo de regresión por cada ubicación

Visualización esquemática: OLS vs. GWR

Regresión ponderada localmente

OLS global

\[\hat{\boldsymbol{\beta}} = \left( \mathbf{X}^T \mathbf{X} \right)^{-1} \mathbf{X}^T \mathbf{y}\]

Una sola solución usando todas las observaciones con igual peso.

GWR (en cada ubicación \(s_i\))

\[ \hat{\boldsymbol{\beta}}(s_i) = \left( \mathbf{X}^T \mathbf{W}_i \mathbf{X} \right)^{-1} \mathbf{X}^T \mathbf{W}_i \mathbf{y} \]

donde \(\mathbf{W}_i\) es una matriz diagonal \(m \times m\) de pesos espaciales, específica para el punto \(i\):

\[\mathbf{W}_i = \text{diag}(w_{i1}, w_{i2}, \dots, w_{im})\]

Cada observación \(i'\) pesa según su distancia al punto de calibración \(i\): cuanto más cerca, más peso.

El kernel espacial

El peso \(w_{ii'}\) se define con una función kernel, decreciente en la distancia \(d_{ii'}\) entre \(s_i\) y \(s_{i'}\), y regulada por un bandwidth \(bw\).

Formas de kernel

Kernel exponencial (continuo):

\[w(s_i, s_{i'}) = \exp\left[-\dfrac{d(s_i,s_{i'})}{bw(s_i)}\right]\]

Kernel gaussiano (continuo):

\[w(s_i, s_{i'}) = \exp\left(-\dfrac{1}{2}\left(\dfrac{d(s_i, s_{i'})}{bw(s_i)}\right)^2\right)\]

Kernel bi-cuadrático (compacto, bisquare):

\[w(s_i,s_{i'}) = \begin{cases} \left[1-\left(\dfrac{d(s_i,s_{i'})}{bw(s_i)}\right)^2\right]^2 & d(s_i,s_{i'}) < bw(s_i) \\ 0 & d(s_i,s_{i'}) \geq bw(s_i) \end{cases}\]

Bandwidth fijo vs. adaptativo

Fijo o basado en distancia

  • Radio de búsqueda fijo en todo el área de interés.
  • Interpretación directa en unidades de distancia (m, km)
  • Aplicable cuando la densidad de puntos es homogénea.
  • Riesgo de desbalance en número de observaciones

Adaptativo, basado en el número de vecinos cercanos

  • Interpretación más difícil o menos intuitiva
  • Se ajusta a la densidad de puntos y áreas irregulares
  • Mantiene número constante de observaciones, pesos según distancia

Selección del bandwidth

Trade-off central de GWR:

Si \(bw\) es chico

  • Modelo muy local
  • Alta varianza: menos observaciones para estimar los coeficientes.
  • Mayor riesgo de sobreajuste
  • Autocorrelación modelada como heterogeneidad de coeficientes

Si \(bw\) grande

  • Modelo más suave
  • Se acerca al OLS global
  • Subajuste de la variación local
  • Autocorrelación queda en los residuos

Se puede optimizar

  • AICc: penaliza la complejidad (gl efectivos)
  • CV: minimiza el error de predicción

GWR más allá de R

GWmodel no es la única implementación de GWR en R.

R

  • spgwr: paquete basado en sp, más liviano, menos funciones.
  • GWmodel3: nueva generación de GWmodel, no disponible en CRAN todavía.

Python

  • mgwr (ecosistema pysal).

Standalone

  • GWR4 (standalone): software histórico de Fotheringham/Charlton.

Integrado a GIS

  • ArcGIS: herramienta Geographically Weighted Regression nativa.
  • QGIS: plugin de GWR.

El dataset: Las Rosas, 1999

agridat::lasrosas.corn: monitor de rendimiento de un lote de maíz con nitrógeno variable (Las Rosas, Río Cuarto, Córdoba). Puntos espaciados ~9.8 m dentro y entre franjas.

  • n = 1738 observaciones (subset año 1999, de 3443 totales, incluyendo 2001)
  • Variable respuesta (Y): yield: rendimiento de maíz (qq/ha)
  • Variable explicativa (X): bv: brightness value, proxy (inverso) de materia orgánica del suelo, derivado de imagen aérea/satelital

Repaso

  • Regresión global asume relaciones constantes en el espacio; en algunos escenarios eso puede no ser realista

  • Un paso intermedio (SAR/CAR) corrige autocorrelación en los residuos, pero sigue dando un único set de coeficientes

  • GWR estima un modelo distinto en cada ubicación, ponderando observaciones cercanas vía un kernel y un bandwidth

  • El bandwidth se optimiza (AICc o CV), no se elige a mano

  • Con varios predictores (Georgia), GWR usa un único bandwidth para todas las variables, ¿alcanza?

  • Se ajustó un modelo GWR sobre Las Rosas, falta explorarlo (diagnóstico)
